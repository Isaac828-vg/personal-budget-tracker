# Personal Budget & Expense Tracker ## Project Description This is a simple web-based Personal Budget and Expense Tracker built using HTML and CSS. The project helps users record and view their daily expenses by name, amount, category, and date. ## Project Files ### 1. index.html This file contains the structure of the website, including: - Page heading and logo. - Add Expense form. - Category dropdown with five options. - Expense table with five sample records. - Collapsible instructions section. - Embedded YouTube video. ### 2. style.css This file controls the appearance of the website, including: - Page background and layout. - Form and button styling. - Expense table borders and colours. - Alternating table row colours. - Hover effects. - Input focus effects. - Responsive video display. ## HTML and CSS Features - Semantic HTML elements. - HTML table using table, thead, tbody, tr, th, and td. - Form with input fields and select dropdown. - Image and iframe multimedia elements. - Details and summary elements. - Advanced CSS selectors. - Hover and focus effects. ## Technologies Used - HTML5 - CSS3 ## Author Isaac Ladu James My Budget Tracker
